# การทดสอบ

integration: ฐานข้อมูลจริงในระบบทดสอบและขอบเขตสิทธิ์
e2e: เส้นทางลูกค้า ร้าน และผู้ดูแลหลายขนาดจอ
load: การจอง/ซื้อพร้อมกัน ความหน่วง และการตรวจยอดหลังโหลด

ยังไม่มี test suite ที่รันได้ ต้องเพิ่มพร้อม implementation ทดสอบ API ข้ามร้าน โซนเฉพาะอาหาร สต็อกสุดท้าย webhook ซ้ำ และการคืนเงินบางส่วน
