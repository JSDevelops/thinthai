# ThinThai Account + Stays UX/UI

Created with built-in imagegen on 2026-10-08. Eight mobile concept screens across three boards. No application code or authentication integration changed. Fictional personal information and lodging bookings.

1. Guest account, phone/email login, OTP verification with an annotated expired-code example.
2. Registration, success, account dashboard with lodging reservation shortcut.
3. Profile editing and lodging operator application with approval progression.

Implementation notes: OTP expired example is a separate design state, never show a resend cooldown and available resend simultaneously. Disable submit until valid inputs; support paste and autofill. Preserve return route after authentication and avoid duplicate accounts. Marketing opt-in is optional and unchecked. Phone verification is not identity or merchant verification. New users have no bookings: show an empty state until they book; the illustrated reservation belongs to a returning-user dashboard. Preserve original brand assets in production. Render actual Thai text and test contrast and responsive layouts. Admin roles cannot be self-selected. Lodging applications must be approved before booking availability is published. The host application image shows its first step, not the complete application workflow. Booking and payment status remain separate.
