# ภาพออกแบบ ThinThai

ไฟล์ใน references เป็นภาพแนวคิดเดิม ชื่อที่ปรากฏในภาพยังอาจเป็น “เที่ยวชุมชน” ชื่อผลิตภัณฑ์ที่ใช้พัฒนาคือ ThinThai

- Admin Panal.png: หน้าจอแยกสี่บทบาท
- Smart Phone.png: หน้าจอมือถือ
- Tablat.png: หน้าจอแท็บเล็ต
- หน้าแพล็ตฟอร์ม.png: หน้าเว็บลูกค้าและการจอง

ภาพ ราคา หมุด และข้อมูลบนหน้าจอเป็นตัวอย่าง ไม่ใช่ข้อมูลร้านหรือแผนที่บริการจริง โฟลเดอร์ tokens เตรียมไว้สำหรับสี ฟอนต์ ระยะห่าง และขนาดปุ่มที่ตรวจการเข้าถึงแล้ว
