# ThinThai

**แอปเดียวครบ จองทริป ช้อปสินค้าชุมชน**

เที่ยวไทยให้ถึงถิ่น สัมผัสวิถีชีวิต วัฒนธรรมและธรรมชาติอันงดงาม

## สถานะ

เพิ่มการสร้าง/แก้ไข/พักร้าน ปักหมุด และตั้งรัศมีจัดส่งอาหารแล้ว ดู [คู่มือร้านค้า](docs/STORE_MANAGEMENT.md)

เว็บและ API รันในเครื่องได้แล้ว เชื่อม PostgreSQL พร้อมสมัครสมาชิก เข้าสู่ระบบ เปลี่ยนรหัสผ่าน และสิทธิ์ 4 บทบาท ข้อมูลร้านค้ายังเป็นตัวอย่าง ยังไม่มีการชำระเงินจริง อ่าน [คู่มือเริ่มใช้งาน](docs/LOCAL_DEVELOPMENT.md) และ [ผลทดสอบ](docs/VALIDATION.md)

## โครงสร้าง

```text
apps/
  web/          หน้าจอรวมแต่ละบทบาทที่รันได้ในระยะนี้
  admin/        เตรียมแยกเว็บ Admin ในอนาคต
  api/          Backend แบบแบ่งโมดูล
  worker/       เตรียมพัฒนางานเบื้องหลัง
packages/
  ui/           องค์ประกอบหน้าจอร่วม
  contracts/    สัญญา API
  i18n/         ข้อความและภาษา
  config/       การตั้งค่าพัฒนาร่วม
  domain/       กฎธุรกิจฝั่งเซิร์ฟเวอร์ที่ API และ Worker ใช้ร่วมกัน
database/      migrations และข้อมูลทดสอบ
design/        ภาพอ้างอิงและแนวทาง UI
docs/          ข้อกำหนดและแผนพัฒนา
infra/         โครงสร้างพื้นฐาน
tests/         ทดสอบข้ามระบบ
```

## แนวทางเทคโนโลยี

Next.js 16.3.8 + React 19.3.0 สำหรับเว็บ, NestJS 12.1.2 บน Node.js 24 สำหรับ API, PostgreSQL 16 สำหรับข้อมูลหลัก ใช้ npm workspaces พร้อม package-lock.json ส่วน PostGIS ยังอยู่ขั้นถัดไป packages ที่แยกไว้ยังเป็นโครงสร้างเตรียมพัฒนา

## กฎหลัก

จำกัดโซนเฉพาะอาหารส่งทันที หมวดท่องเที่ยว กิจกรรม ที่พักและสินค้าทั่วไปใช้กฎบริการของตนเอง ตรวจสิทธิ์และขอบเขตข้อมูลที่ Backend ทุกครั้ง ข้อมูลจำลองและภาพออกแบบไม่ใช่หลักฐานว่าธุรกรรมทำงานจริง

## เริ่มใช้งาน

ทำตาม [คู่มือเริ่มต้น](docs/LOCAL_DEVELOPMENT.md): ติดตั้ง dependencies → เริ่มฐานข้อมูล → migrate → seed → เปิดเว็บ http://127.0.0.1:3200 บัญชีพัฒนารหัสผ่านสุ่มเก็บใน `.local/dev-accounts.md` ไม่ใส่ใน Git

## ลงทะเบียนเปิดร้าน

สมัครผู้ประกอบการและ Admin ตรวจอนุมัติได้แล้ว ดู [วิธีใช้และผลตรวจ](docs/REGISTRATION_REVIEW.md)

## สินค้าและสต๊อก

เพิ่มเมนูสินค้า รูปปก ราคา วิธีรับสินค้า สต๊อกและประวัติ พร้อมหน้าตัวอย่าง /catalog อ่าน [คู่มือสินค้า](docs/PRODUCT_MANAGEMENT.md)

## แบรนด์ ThinThai

ใช้โลโก้หมุดถิ่นไทยกับเว็บไซต์และไอคอนแล้ว ดู [คู่มือแบรนด์](design/brand/README.md) และชุดไฟล์ design/brand/ThinThai-brand-kit.zip

## หน้าเว็บ คำสั่งซื้อ และทริป

หน้าแรกใหม่ `/` ใช้เอกลักษณ์เขียว–ทอง ThinThai; พื้นที่เข้าสู่ระบบและจัดการย้ายไป `/workspace`

- `/catalog` เลือกสินค้าและตะกร้า → `/orders` ดูคำสั่งซื้อ
- `/trips` ค้นหาและส่งคำขอจอง → `/bookings` ดูทริปของฉัน
- ผู้ประกอบการจัดการสินค้า คำสั่งซื้อ ทริปและรอบที่ `/workspace`

อ่าน [คู่มือคำสั่งซื้อ](docs/ORDERS.md) และ [คู่มือทริปและการจอง](docs/TRIPS_AND_BOOKINGS.md)
เพิ่มทริปจำลองด้วย `npm run db:seed-trips` หลัง migrate และ seed บัญชี รุ่นนี้ยังไม่รับชำระเงินจริง
