# ThinThai — สถานะการพัฒนา

## เสร็จแล้ว

- โครงสร้าง monorepo และเอกสารผลิตภัณฑ์
- เว็บ responsive และ NestJS API
- PostgreSQL ในเครื่อง พร้อม migration ที่รันซ้ำได้และ seed แยก
- สมัคร/เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน, logout, เปลี่ยนรหัสผ่าน
- เซสชันถาวรและสิทธิ์ร้านค้า/จังหวัดจากฐานข้อมูล
- automated tests ของ API และหน้าจอ

- สร้าง/แก้ไข/พักร้าน, ปักหมุด, โซนรัศมีอาหาร และประวัติการแก้ไข

## ขั้นถัดไป

1. การแนบเอกสาร/ยืนยันตัวตน และการเชิญสมาชิก/โอนร้าน
2. พื้นที่จริงครบประเทศและ PostGIS สำหรับหมุด/โซนจัดส่งอาหารเท่านั้น
3. สินค้า/สต๊อก/การจองพร้อมการทดสอบธุรกรรม
4. ยืนยันอีเมล กู้บัญชี MFA และเตรียม deployment เมื่อมีบริการภายนอกพร้อม
