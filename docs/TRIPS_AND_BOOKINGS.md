# ทริปและการจอง ThinThai

## เริ่มใช้งาน

1. `npm run db:migrate` เพื่อเพิ่มตารางทริป รอบเดินทาง และการจอง
2. `npm run db:seed-trips` เพื่อเพิ่มข้อมูลตัวอย่าง 3 ทริปในเครื่อง (ต้องรัน db:seed มาก่อน)
3. เปิด `/trips` เพื่อค้นหาทริปและเลือกกิจกรรม เปิด `/bookings` เพื่อดูการจองของตนเอง
4. เข้าสู่ระบบที่ `/workspace` บัญชีผู้ประกอบการหรือผู้ดูแลเลือกเมนู **ทริปและการจอง**

คำสั่ง seed เพิ่มข้อมูลจำลองที่มีป้ายตัวอย่าง ไม่แก้ข้อมูลเดิมเมื่อรันซ้ำ ไม่สร้างรอบใหม่อัตโนมัติเมื่อรอบเก่าผ่านไป

## ผู้ประกอบการ

เลือกผู้ให้บริการจากร้านที่ดูแล เพิ่มชื่อ รายละเอียด สิ่งที่รวม จุดนัดพบและช่องทางติดต่อ ประเภทกิจกรรม ระยะเวลา และราคาต่อคน บันทึกฉบับร่างได้
เปิดสถานะเผยแพร่และเพิ่มรอบล่วงหน้าอย่างน้อย 1 ชั่วโมง ร้านต้องเปิดใช้งานด้วยจึงแสดงให้ผู้ใช้เห็น
เวลาในฟอร์มเป็นเวลาไทย (Asia/Bangkok) บันทึกเป็น timestamptz ในฐานข้อมูล
จำนวนที่นั่งต่อรอบ 1–1,000 ที่ รอบเดิมแก้เวลาและความจุไม่ได้ ให้ปิดรับรอบและสร้างรอบใหม่
การปิดรับรอบ/พักทริปไม่ยกเลิกการจองเดิม ต้องจัดการการจองแยกกัน
แก้ชื่อ รายละเอียด ราคาและสถานะทริปได้ มี version ป้องกันเขียนทับ การจองก่อนหน้าเก็บชื่อ ราคา วันและจุดนัดพบขณะจอง

## ผู้เดินทาง

ค้นหาทริปตามชื่อ จังหวัด ชุมชน หรือประเภท เลือกรอบ จำนวน 1–10 คนและข้อมูลติดต่อ ตรวจยอดแล้วส่งคำขอจองทดลอง
การส่งคำขอกันที่นั่งทันทีและแสดงสถานะรอยืนยัน ผู้ประกอบการยืนยันหรือปฏิเสธได้
ผู้เดินทางยกเลิกเองได้ขณะรอยืนยันและก่อนวันเริ่ม ผู้ประกอบการยกเลิกรายการที่ยืนยันแล้วได้ก่อนเริ่มทริป โดยต้องระบุเหตุผล
หลังเริ่มทริป ผู้ประกอบการจบรายการที่ยืนยันแล้วได้ ประวัติทุกการเปลี่ยนสถานะดูได้ในการจอง

## ความถูกต้องและสิทธิ์

- ราคาตรวจซ้ำที่เซิร์ฟเวอร์ ไม่มีการเชื่อยอดจากผู้ใช้
- ล็อกแถวร้านและรอบใน transaction กันจองเกินจำนวน; ยกเลิก/ปฏิเสธคืนที่นั่งครั้งเดียว
- รหัสคำขอ UUID ป้องกันส่งซ้ำ รหัสเดิมกับข้อมูลต่างกันถูกปฏิเสธ
- ผู้ใช้เห็นการจองของตน ร้านเห็นเฉพาะที่ดูแล Admin เห็นเฉพาะจังหวัดที่ได้รับมอบหมาย Super Admin ดูได้ทุกพื้นที่
- ชื่อผู้ติดต่อและโทรศัพท์ไม่แสดงในข้อมูลทริปสาธารณะ
- ขอบเขตจัดส่งอาหารไม่มีผลกับทริป รวมถึงกิจกรรมทำอาหาร

## ขอบเขตรุ่นนี้

ยังไม่มีรับชำระเงินจริง คืนเงิน แจ้งเตือนอีเมล/ข้อความ การหมดอายุคำขอจองอัตโนมัติ หรือการจัดการคืนเงินตามนโยบายธุรกิจ
คำขอรอยืนยันกันที่นั่งจนกว่าจะยกเลิก/ปฏิเสธหรือดำเนินการต่อ ต้องกำหนดนโยบายหมดอายุและเพิ่ม worker ก่อนเปิดใช้งานจริง
หน้ารายการจำกัด 100 รายการล่าสุด; รอบในหน้าจัดการแสดงเฉพาะอนาคต ประวัติการจองยังอ่านได้ การแบ่งหน้าและข้อมูลท่องเที่ยวเต็มประเทศเป็นขั้นต่อไป
ภาพประกอบเป็นภาพวาด ไม่ใช่ภาพสถานที่จริง ทริปจาก seed เป็นข้อมูลจำลองเพื่อทดสอบเท่านั้น

## การตรวจสอบ

`npm run test:integration` ตรวจสิทธิ์ รอบปิด/ผ่านไป ราคา การจองพร้อมกัน การคืนที่นั่ง การกดซ้ำ ประวัติ และข้อมูลอยู่หลัง API restart
`npm run test:trips-ui` ตรวจเพิ่มทริป/รอบ ค้นหา ส่งคำขอ ผู้ใช้ยกเลิก ผู้ประกอบการปฏิเสธ/ยืนยัน และภาพ desktop/tablet/mobile
ภาพอยู่ใน `design/previews/trips/`
