# ตะกร้าและคำสั่งซื้อ

เลือกสินค้าที่ /catalog ดูรายการของตนเอง /orders ร้านจัดการที่ /workspace → คำสั่งซื้อ → รายการของร้าน
ตะกร้าแยกหนึ่งร้านและหนึ่งวิธีรับสินค้าต่อคำสั่งซื้อ เก็บในหน่วยความจำหน้าเว็บ รีเฟรชแล้วตะกร้าหาย ราคาคำนวณซ้ำที่เซิร์ฟเวอร์
คำสั่งซื้อกันสต๊อกทันที ใช้รหัสคำขอป้องกันการกดซ้ำ ร้านรับ/ปฏิเสธรายการได้ ลูกค้ายกเลิกได้ก่อนร้านรับ สต๊อกคืนครั้งเดียวเมื่อยกเลิก/ปฏิเสธ เมื่อร้านทำรายการเสร็จสิ้นจะตัดยอดที่กันไว้
การจัดส่งทันทีตรวจโซนเฉพาะอาหาร หมวดอื่นไม่ถูกบังคับด้วยโซนอาหาร
รายการบันทึกใน PostgreSQL พร้อมประวัติและราคาสินค้าขณะซื้อ จำกัดสิทธิ์ผู้ซื้อ ร้าน และผู้ดูแลตามพื้นที่
ยังไม่มีชำระเงิน ค่าขนส่ง คนขับ หรือการหมดอายุคำสั่งซื้ออัตโนมัติ
ทดสอบ: npm run test:integration และ npm run test:orders-ui
