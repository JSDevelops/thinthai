# ผลตรวจสอบ ThinThai — ระบบบัญชีและฐานข้อมูล 4 ตุลาคม 2026

- PostgreSQL 16.11 แยกพอร์ต 55433 ฐาน development/test
- migration 001 และ 002 ผ่าน; รันซ้ำไม่ลบข้อมูล; seed ซ้ำไม่สร้างบัญชีซ้ำหรือเปลี่ยนรหัสผ่าน
- build Next.js / NestJS และ typecheck ผ่าน
- unit: 4 กรณีขอบเขตสิทธิ์ ผ่าน
- API integration กับ PostgreSQL: 13 กรณี ผ่าน
  - ถอด demo endpoints และปฏิเสธการปลอม role
  - สมัครสมาชิกเป็น USER เท่านั้น, เก็บ hash, normalize email, ป้องกันอีเมลซ้ำ
  - ไม่เปิดเผยการมีอยู่ของบัญชีในข้อความ login ผิด
  - ป้องกันข้ามร้านและข้ามจังหวัด, food-only delivery
  - สิทธิ์ที่แก้ใน DB มีผลกับ session เดิมทันที
  - บัญชีและ session อยู่หลังเปิด API ใหม่
  - เปลี่ยนรหัสผ่านยกเลิกทุก session และรหัสเดิมใช้ไม่ได้
  - session หมดอายุ/บัญชีปิดใช้งานถูกปฏิเสธ
  - CSRF และ input validation
  - rate limit atomic และอยู่หลัง restart
  - migration ซ้ำคงข้อมูล, FK ป้องกันพื้นที่ไม่สัมพันธ์กัน
  - ปฏิเสธ startup production ก่อนพร้อม deployment
- Chrome UI: desktop 1440×1000, tablet 820×1180, mobile 390×844 ผ่าน
- ทดสอบ login, refresh, ร้านตามสิทธิ์, food-only, logout, signup, เปลี่ยนรหัสผ่าน, login ด้วยรหัสใหม่
- ไม่มี horizontal overflow และ browser runtime errors ในกรณีทดสอบ
- ภาพปัจจุบัน: design/previews/auth

ยังไม่ได้ทดสอบอุปกรณ์จริงทุกระบบ, Safari, load test, production deployment หรือการชำระเงินจริง ระบบยืนยันอีเมล กู้บัญชี และ MFA ยังไม่มี
