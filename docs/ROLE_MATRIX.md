# สิทธิ์ตั้งต้น

| บทบาท | ขอบเขตข้อมูล | งานหลัก |
|---|---|---|
| User | ของตนเอง | จอง ซื้อ ติดตาม และขอช่วยเหลือ |
| Merchant | ร้านที่เป็นสมาชิกตามสิทธิ์ | รายการขาย ออเดอร์ บริการ และรายรับ |
| Admin | พื้นที่และความสามารถที่มอบหมาย | ตรวจร้าน ดูแลงาน และโซนอาหาร |
| Super Admin | งานส่วนกลางตามสิทธิ์ | มอบบทบาท ตั้งค่า และตรวจประวัติ |

ตรวจสิทธิ์ทุก API ไม่พึ่งเมนูที่ซ่อน หนึ่งคนมีหลายบทบาทได้แต่ยกระดับตนเองไม่ได้ แยกสิทธิ์การเงินจากการตรวจเนื้อหา เก็บประวัติการเปลี่ยนสิทธิ์และข้อมูลสำคัญ
