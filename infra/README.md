# โครงสร้างพื้นฐาน

เตรียมพื้นที่สำหรับ development, staging และ production ยังไม่มีทรัพยากร Cloud ถูกสร้างหรือมีค่าใช้จ่ายจากโครงสร้างนี้ เลือกผู้ให้บริการและ region ก่อนสร้าง Infrastructure as Code

Secret ต้องอยู่ภายนอก repo ตั้งงบแจ้งเตือน backup และแผนกู้คืนก่อนเปิดจริง แยกบัญชีบริการและข้อมูลแต่ละ environment
